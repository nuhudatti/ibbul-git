## Deploy on Vercel

The easiest way to deploy your Next.js app is to use the [Vercel Platform](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme) from the creators of Next.js.

### Persistent runtime data

This app stores profile and portfolio data in a runtime data directory. In production, set a writable `DATA_DIR` environment variable to a durable path so created student accounts, avatars, and portfolio artifacts persist across server restarts and deployments.

Example Vercel env vars:

- `DATA_DIR` = `/tmp/ula-data`
- `JWT_SECRET` = `your-long-secret`

If `DATA_DIR` is not set, the app falls back to `.data` in development and `tmp/ula-data` in production.

Check out our [Next.js deployment documentation](https://nextjs.org/docs/app/building-your-application/deploying) for more details.
